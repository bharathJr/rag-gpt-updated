# FSM RAG Chatbot

A Streamlit web app to chat with your uploaded FSM (Finite State Machine) notes using LangChain and OpenAI.

## Setup

1. Upload your `.env` file locally or set `OPENAI_API_KEY` in Streamlit Cloud Secrets.
2. Run locally with:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Or deploy on [https://streamlit.io/cloud](https://streamlit.io/cloud).
